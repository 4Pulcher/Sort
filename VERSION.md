# VERSION.md

## Basics

**Sort** - Media-Intelligent File Organizer by **Ali ISIN (HEjder / Ejder)**.

- Repository: <https://github.com/4Pulcher/Sort>
- Download: <https://github.com/4Pulcher/Sort/archive/refs/heads/main.zip>
- Lineage: V1.0 to V22, 105 versions, four languages (Bash, FreePascal, Python, C++17 + Qt6 GUI).
- Layout: one directory per language at the root, one sub-directory per version
  (`SHELL/Sort-V22/...`), every function of every version extracted under
  `FUNCTIONS/$LANG/<Name>/<Name>-V#.#`, and non-lineage material in `VARIA/`.

## Highlights

- **V1.x - V15.x**: the Ejder-scripts era - compact sorters growing into the
  threaded, magic-aware organizer (see `VARIA/Docs/Sort-Versions.md`).
- **V16.x - V17.x**: the function-toolkit rewrite era, self-contained editions,
  20 UI languages.
- **V18 - V19**: the multi-language era (Python + C++17 + Qt6 GUI).
- **V20**: raw device scan (`--scan-raw`), 237-signature engine.
- **V21**: filesystem partition scan (`--scan=FSFORMAT`, MBR/GPT + lost
  partitions, carving, GUI fragment tree).
- **V22**: signature table expanded to 260 formats from Garry's magic-number CSV.
