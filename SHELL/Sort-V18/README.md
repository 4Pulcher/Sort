# Sort V18 - Bash edition

V18 adds the fourth language to the family: a single-file, dependency-free
**C++17** edition (`Sort-V18.cpp`), alongside the usual Bash, FreePascal
and Python trio. All four editions now implement the same feature union,
including the full 237-signature `--magic` detection table inherited from
V17.5.

## Caution - test phase

**Be careful with this script.** The Sort code is in a **test phase**: every
version passes syntax checks and the available self-tests, but it is not
field-tested on real data. Always run it on a scratch copy first, and read the
dry-run preview before confirming any action.

## Build / run

`chmod +x Sort-V18.sh && ./Sort-V18.sh (bash 4+)`
